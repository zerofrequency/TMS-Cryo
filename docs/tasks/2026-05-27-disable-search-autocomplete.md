# Disable Browser Autocomplete On Business Search Inputs

Status: Ready for Development

## Owner Role

UI Support Developer

## Background

On the Appointments page, the search input can show browser autocomplete suggestions such as unrelated shopping/product terms. These suggestions come from the browser's saved input history, not from TMS data or Supabase.

This creates confusion because users may think the popup is generated by the TMS application.

## Scope

- Disable browser autocomplete/history suggestions on business search inputs.
- Apply the fix consistently to TMS search fields.
- Keep existing search/filter behavior unchanged.

## Out Of Scope

- Changing search logic.
- Changing Supabase queries.
- Changing filter behavior.
- Redesigning the filter panels.
- Clearing the user's browser history or browser settings.

## Requirements

Add appropriate attributes to business search inputs:

```html
autocomplete="off"
spellcheck="false"
```

If Chrome still shows suggestions, add stable page-specific `name` values to reduce autofill matching, for example:

```html
name="appointmentSearch"
name="tripPlanSearch"
name="carrierBillingSearch"
```

Target search inputs:

- Appointment search in `appts.html`
- Trip Plan search in `pages/trip-plans.html`
- Carrier Billing search in `pages/carrier-billing.html`
- Stop ISA / FC search in `pages/create-trip-plans.html`

## Expected Files

Likely files involved:

- `appts.html`
- `pages/trip-plans.html`
- `pages/carrier-billing.html`
- `pages/create-trip-plans.html`

No script changes should be needed unless the implementation discovers a page dynamically creates a search input.

## Acceptance Criteria

- Browser autocomplete suggestions no longer appear on the Appointment search input during normal use.
- Search boxes still filter records as before.
- Placeholder text remains visible when the input is empty.
- No business logic is changed.
- No unrelated UI redesign is introduced.

## Notes For Developer

- This is a UI-only task.
- Do not change data filtering logic.
- Do not change IDs used by existing JavaScript unless scripts are updated accordingly.
- If autocomplete still appears after `autocomplete="off"`, add page-specific `name` attributes before considering other changes.
